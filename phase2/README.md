# Phase 2 — Tabletop decision paths and evidence discipline

**Version 0.2 · FICTIONAL TEACHING CASE · NOT A DELIVERED TABLETOP.**

The six original injects now support **12 alternative decision branches** (safe/unsafe), eight independent evidence challenges, six structured scoring criteria and two clearly labeled **worked model-answer profiles**. There were **no participants**; the profiles are examples of how to score answers, not human performance or an exercise actually conducted.

| File | Purpose |
| --- | --- |
| [Decision branches](data/decision_branches.csv) | Two distinct choices per inject with limitations and points |
| [Evidence challenges](data/evidence_challenges.csv) | Concrete missing evidence and responsible parties |
| [Scoring rubric](data/scoring_rubric.csv) | Consistent 0 / 1 / 2 interpretation |
| [Illustrative model answers](data/illustrative_tabletop_answers.csv) | Two fictional examples, never participant results |
| [Facilitator method](docs/09-tabletop-decision-guide.md) | Safe execution, scoring and escalation boundaries |
| [Evidence method](docs/10-evidence-uncertainty.md) | Observed vs. inferred vs. unverified |

All original decisions and actions remain unapproved and open. No suspected exfiltration is declared proven and the privacy/legal notification gate remains unresolved.

Run `python scripts/score_tabletop.py` to display the *illustrative* model scores. This utility does not contact a vendor, a user or a security system.
